# Changelog

## [1.0.0] - 2026-10-11

### Added
- 9-Slice Optimizer dialog (*Assets › 9-Slice › Optimize 9-Slice…*, *Tools › UI › 9-Slice Optimizer*): shows a sprite with its 9-slice lines and a live preview, shrinks the stretch zones to a chosen Center Width / Center Height.
- An axis with no border on either side is kept whole (3-slice buttons keep their height or width).
- Save As New (a Single sprite with the source's border and import settings) and Replace Source (in place; a sprite sheet with one sprite keeps its sprite name and ID).
- Pixels read from the PNG/JPG file itself; box-filtered, alpha-weighted averaging.
- EditMode tests of the shrink maths.
